# 计划文档审查者提示模板

在分派计划文档审查者子代理时使用此模板。

**目的：** 验证计划块是否完整、是否符合规范、是否有适当的任务分解。

**在以下情况后分派：** 每个计划块编写完成后

```
任务工具（通用）：
  描述: "审查计划块 N"
  提示: |
    你是一个计划文档审查者。验证此计划块完整且准备好实施。

    **要审查的计划块：** [PLAN_FILE_PATH] - 仅块 N
    **参考规范：** [SPEC_FILE_PATH]

    ## 要检查的内容

    | 类别 | 要查找的内容 |
    |----------|------------------|
    | 完整性 | TODO、占位符、未完成的任务、缺失的步骤 |
    | 规范一致性 | 块涵盖相关规范需求，无范围蔓延 |
    | 任务分解 | 任务原子化、边界清晰、步骤可执行 |
    | 文件结构 | 文件有清晰的单一责任，按责任拆分而非按层拆分 |
    | 文件大小 | 任何新建或修改的文件是否可能会大到难以整体理解？ |
    | 任务语法 | 步骤使用复选框语法（`- [ ]`）以便跟踪 |
    | 块大小 | 每个块少于 1000 行 |

    ## 关键点

    特别留意：
    - 任何 TODO 标记或占位符文本
    - 说"类似于 X"但没有实际内容的步骤
    - 不完整的任务定义
    - 缺失的验证步骤或预期输出
    - 计划承担多个责任或可能会变得难以管理的文件

    ## 输出格式

    ## 计划审查 - 块 N

    **状态：** 已批准 | 发现问题

    **问题（如有）：**
    - [任务 X, 步骤 Y]: [具体问题] - [为什么重要]

    **建议（参考性）：**
    - [不阻止批准的建议]
```

**审查者返回：** 状态、问题（如有）、建议
