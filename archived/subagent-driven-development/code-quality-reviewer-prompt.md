# 代码质量审查者提示模板

在分派代码质量审查者子代理时使用此模板。

**目的：** 验证实现构建良好（清晰、已测试、可维护）

**仅在规范一致性审查通过后分派。**

```
任务工具 (superpowers:code-reviewer):
  使用 requesting-code-review/code-reviewer.md 中的模板

  已实现内容: [来自实施者的报告]
  计划或需求: 任务 N 来自 [plan-file]
  基础 SHA: [任务前的提交]
  当前 SHA: [当前提交]
  描述: [任务摘要]
```

**除了标准代码质量问题外，审查者还应检查：**
- 每个文件是否有一个清晰的责任和定义良好的接口？
- 单元是否被分解为可以独立理解和测试？
- 实现是否遵循计划中的文件结构？
- 此实现是否创建了已经很大的新文件，或显著增大了现有文件？（不要标记预先存在的文件大小——关注此变更贡献的内容。）

**代码审查者返回：** 优点、问题（严重/重要/轻微）、评估
